# JunctionNav

Turn-by-turn navigation with junction views for ramps, forks, exits and divider splits, with lane
guidance, live traffic, offline maps for Peninsular Malaysia and the places around you.

- **Open the app:** https://neokrex-source.github.io/junctionnav/
- **Android:** [JunctionNav.apk](https://github.com/neokrex-source/junctionnav/releases/download/android/JunctionNav.apk) (Android 7 or newer). Open it on the phone, tap the downloaded file and allow the install.

This repository only holds what is published: the website with its offline maps and places data
(the `gh-pages` branch), the Android installer (the `android` release) and the traffic news feed
(the `traffic-news` branch). They are built and updated automatically; the source code is private.
